# Documents de l'association — source de contenu

Dépose ici **tous les documents de description de Manssuétude**. Ils serviront à **remplir la base de données** (contenu réel des pages, thèmes, activités, productions, projets, méthode PERCA, etc.) au moment du rebranchement admin ↔ public (Phase E du plan de refonte).

> Formats acceptés : `.pdf`, `.docx`, `.pptx`, `.md`, `.txt`, images. Range-les dans les sous-dossiers ci-dessous si possible.

## Documents EXIGÉS (pour pouvoir remplir la base)

### 1. Identité & présentation
- [ ] Présentation générale de l'association (deck / plaquette) — *ex. « Manssuetude Deck.pdf »*
- [ ] Mission, vision, valeurs
- [ ] Histoire / origine de l'association
- [ ] Statuts (si publics) ou note de présentation officielle
- [ ] Baseline / slogan officiel

### 2. Méthode PERCA
- [ ] Description détaillée de la méthode et **la signification exacte de chaque lettre** P·E·R·C·A
- [ ] Les piliers / étapes, avec un court texte par étape

### 3. Thèmes
- [ ] Liste des **thèmes** (axes de réflexion) avec, pour chacun : titre, description courte, description longue
- [ ] Pour chaque thème : les **séances** rattachées (titre + sujet + date si connue)

### 4. Activités
- [ ] Liste des activités avec : titre, **format** (débat, atelier, séance…), description, date

### 5. Productions
- [ ] Articles, synthèses, notes — avec titre, type, auteur, date, texte (ou fichier joint)

### 6. Projets
- [ ] Liste des projets avec : titre, catégorie, description, objectifs, livrables, statut

### 7. Équipe & réseau
- [ ] Membres / rôles / organigramme
- [ ] Partenaires (noms + logos si disponibles)

### 8. Pages éditoriales
- [ ] Texte de **À propos**
- [ ] Texte de **Nous soutenir** (comment soutenir, dons, mécénat)
- [ ] Texte de **Nous rejoindre** (comment adhérer / participer)

### 9. Contact / formulaire « Nous joindre »
- [ ] Coordonnées officielles (email, téléphone, adresse, réseaux sociaux)
- [ ] Champs souhaités du **formulaire de contact** (nom, email, sujet, message… et destinataire des messages)

### 10. Charte & médias
- [ ] Charte graphique (couleurs, polices) si elle existe
- [ ] Logo(s) en bonne définition (déjà fourni : logo actuel)
- [ ] Photos / visuels libres de droits à utiliser sur le site

---

**Quand c'est prêt :** préviens-moi, je lis les documents et je remplis la base (table `pages` + collections) avec le contenu réel, en Phase E.
